Randome Clickable Prototype

유튜브 한 편이
하루 영어 루프로

사용자가 넣은 유튜브 URL에서 영어 스크립트를 추출하고, 중요한 문장을 하루 동안 랜덤 푸시로 다시 꺼내 보여주는 서비스 초안입니다.

포함한 플로우

  • 온보딩과 가치 제안
  • 유튜브 URL 입력
  • 스크립트 분석 및 문장 추출
  • 오늘의 랜덤 푸시
  • 문장 카드와 한국어 해석
  • 빈칸 완성과 응용 연습
  • 영상별 문장 라이브러리

조작 방법

  • 오른쪽 모바일 화면 안 버튼으로 흐름 이동
  • 상단 Demo Flow 칩으로 원하는 화면 점프
  • 연습 화면에서는 정답 보기를 직접 눌러볼 수 있음

제품 방향

  • 일반 영어 앱이 아니라 개인화된 문장 리마인더
  • 번역만 보여주지 않고 짧은 사고 과제를 함께 제공
  • 하루 3~5회 랜덤 푸시로 반복 노출
